# U-Link v0.5.2

发布日期：2026-11-15

## 改动

- 桌面端 `u-link.log` 在正常运行中按 10 MiB 分段轮转，保留最多三个编号备份；跨进程锁避免多个桌面进程同时改写同一日志。
- 启动时检测超限日志并尝试轮转。轮转失败时仍继续启动并追加日志；该降级情况下日志文件可能继续超过 10 MiB。
- 修复企业 IT 说明、CLI 说明和 relay Skill 的失效相对链接；README 现在区分 GitHub Release 标签与 CLI 能力文档版本。

## 验证

- `go vet ./...`
- Windows/amd64 桌面测试包与托盘程序交叉编译
- Markdown 相对链接扫描：0 个断链
